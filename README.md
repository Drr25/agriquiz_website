# AGRIQUIZ 🌱
### Interactive Quiz Engine with Analytics Tuned for the Agriculture Board Examination

AGRIQUIZ is a web-based review and assessment platform designed to help Agriculture students prepare for the **Agriculturist Licensure Examination (ALE)**. It provides centralized access to reviewer materials, interactive practice quizzes, immediate feedback, and performance analytics to support students in monitoring their learning progress.

## 🎯 Project Objectives

- Provide a centralized platform for Agriculture review materials.
- Allow students to take interactive practice quizzes based on major Agriculture subjects.
- Provide immediate feedback on incorrect answers.
- Track quiz scores, performance, and areas that need improvement.
- Help administrators manage student accounts, reviewers, quizzes, and performance records.

## ✨ Key Features

### Student Module
- Student login and dashboard.
- Access to Agriculture reviewer materials.
- Interactive multiple-choice practice quizzes.
- Immediate feedback for incorrect answers.
- Quiz results and score summaries.
- Performance tracking and analytics.
- Progress monitoring by subject area.

### Administrator Module
- Student account management.
- Upload and manage reviewer materials.
- Create and manage practice quizzes.
- View student quiz performance.
- Manage pre-board examination records.
- Profile management.

## 📚 Agriculture Subject Areas

## 💻 Installation and Setup

### Requirements
- XAMPP
- PHP
- MySQL
- Web browser
- Code editor (Visual Studio Code recommended)

### Local Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Drr25/agriquiz_website.git
   ```

2. Move the project folder into your XAMPP `htdocs` directory.

3. Start Apache and MySQL using XAMPP Control Panel.

4. Open phpMyAdmin:

   ```text
   http://localhost/phpmyadmin
   ```

5. Create a MySQL database using the database name configured in your project.

6. Import the provided database SQL file, if available.

7. Configure your database connection using your local database configuration file.

8. Open the website in your browser:

   ```text
   http://localhost/website_agriquiz/
   ```

## 🌐 Deployment

AGRIQUIZ is designed to run on PHP-compatible web hosting with MySQL database support.

## 📊 Project Scope

AGRIQUIZ focuses on providing review materials, practice quizzes, quiz feedback, and analytics for Agriculture students preparing for the Agriculturist Licensure Examination.

Its analytics are based on recorded quiz performance and do not include attendance, classroom participation, or other written examination results.
